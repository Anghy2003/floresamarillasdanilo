# Flores Para Andrea 🌻

Una página de girasoles para el **21 de septiembre**, pensada para verse en el celular.

👉 **Verla en línea:** https://anghy2003.github.io/floresamarillasdanilo/

## Qué tiene

- **Girasoles dibujados por código**, no imágenes. El centro usa la espiral real de la
  flor (ángulo áureo de 137,5°) con ~720 semillas, dos coronas de 21 pétalos cada una
  con degradado y nervaduras, brácteas, tallos con volumen y hojas de borde serrado.
- **Escena nocturna** con luciérnagas y pétalos cayendo.
- **Al tocar la pantalla**: estallido de pétalos, vibración y una nota musical.
- **Reproductor** con una melodía original generada por el navegador (Web Audio),
  y un botón ♪ para poner una canción guardada en el propio teléfono.
- **Una nota** que se abre con el botón «ábreme ✿».
- **Modo limpio** (botón ⛶ abajo a la derecha): esconde los controles para grabar la pantalla.

## Cómo usarla

Es un solo archivo, `index.html`, sin dependencias ni instalación.
Ábrelo en un navegador — en el celular tiene que ser un navegador de verdad
(con barra de direcciones), no el visor de documentos de WhatsApp o Archivos,
porque ese visor no ejecuta JavaScript y los girasoles no se dibujan.

## Nota sobre la música

La melodía incluida es original, compuesta con osciladores de Web Audio.
No se incluye ninguna canción con derechos de autor: para eso está el botón ♪,
que lee un archivo desde tu propio dispositivo y no lo sube a ningún lado.
